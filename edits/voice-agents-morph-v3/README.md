## New motion language
One container continuously changes its dimensions, radius, position and fill: interview window → YEARS timeline → projected wire globe → effort slider → EARLY toggle → interview/priority player → product-to-market route → audience network → voice capsule → cobalt Voice Agents payoff.

Geometry is driven by analytic critically damped responses. Local content is clipped to the same container; a custom cursor triggers the interactions. Source-speech waveforms, active-word captions, quiet original electronic pulse and interface sounds follow the narration.

All product-like views are **illustrative concept graphics**, not screenshots or claims about an actual app. No invented percentages, commercial performance metrics, speaker identities or company branding are introduced.
